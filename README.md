# Decvade - TG

Приложение для Android: проверяет, свободен ли юзернейм в Telegram, и умеет само искать свободные.

Как работает: открывает страницу t.me/ник и смотрит, есть ли у неё владелец. Без аккаунта и без сервера, всё на твоём телефоне.

## Как собрать APK
1. Залей все файлы в репозиторий на GitHub.
2. Вкладка Actions -> Build APK -> Run workflow (или просто сделай push).
3. Когда сборка закончится, открой её и скачай Decvade-TG-apk внизу страницы.

## Важно
"Свободен" значит, что у страницы нет владельца. Telegram всё равно может не дать занять ник (он зарезервирован или продаётся на Fragment).
