# Decvade - TG

Приложение для Android, которое локально генерирует варианты юзернеймов и проверяет выбранный ник по публичным страницам Telegram и Fragment.

## Что умеет

- Проверять введённый ник по нажатию кнопки.
- Генерировать варианты по префиксу, длине и настройкам символов.
- Использовать локальный словарь `app/src/main/assets/words.txt`.
- Проверять выбранный вариант нажатием на него в списке.

Генерация выполняется на устройстве. Сетевые запросы отправляются только для ника, который пользователь явно выбрал для проверки; фонового перебора и запросов для всего списка нет.

## Как трактовать результат

Результат проверки предварительный: Telegram может ограничить ник, даже если публичная страница не найдена. Публичная страница Fragment не всегда позволяет определить, занят ли конкретный ник; в таком случае приложение сообщает, что результат неоднозначен, а не утверждает, что ник свободен.

## Свой словарь

Слова находятся в `app/src/main/assets/words.txt`, по одному на строку. Генератор отфильтрует слова по заданным ограничениям.

## Как скачать APK через GitHub Actions

1. Открой вкладку **Actions** в репозитории и выбери workflow **Build APK**.
2. Открой завершившийся запуск сборки.
3. Скачай артефакт **Decvade-TG-apk** и распакуй его.
4. Установи `app-debug.apk` на устройство Android 7.0 или новее.

Сборка также автоматически запускается при push в репозиторий.

## Дисклеймер

Проект не связан с Telegram и не одобрен им. Результат публичной проверки не гарантирует, что ник можно занять.
